# Security policy

## Supported versions

Security fixes are currently applied to the latest release on the `main`
branch. Older releases may not receive fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. Use GitHub's
private vulnerability reporting for this repository when available. If it is
not available, contact the repository owner through GitHub and include:

- The affected version or commit.
- Reproduction steps or a proof of concept.
- The expected and observed behavior.
- Any suggested mitigation.

Please allow reasonable time for triage and remediation before public
disclosure. Do not include personal data or secrets in the report.
